Часть 1. Как устроен сайт?

Когда мы открываем сайт, браузер получает специальные файлы и показывает их пользователю.

В веб-разработке есть три основных технологии:

  • HTML — содержание страницы
  • CSS — внешний вид
  • JavaScript — поведение страницы
Представьте человека:

HTML — скелет
CSS — одежда и внешний вид
JavaScript — действия и поведение

Сегодня начинаем с HTML.

Часть 2. Первый HTML-файл

1. Создаём папку проекта

Создайте на компьютере папку:

my-first-site

Внутри создайте файл:

index.html

2. Первый код

Вставьте в файл:

<!DOCTYPE html>

<html lang="ru">

<head>
    <meta charset="UTF-8">
    <title>Мой первый сайт</title>
</head>

<body>

    <h1>Привет!</h1>

    <p>Это мой первый сайт.</p>

</body>

</html>
Задание:
  1. Сохраните файл.
  2. Откройте index.html в браузере.
  3. Измените текст.
  4. Сохраните файл ещё раз.
  5. Обновите страницу.

Часть 3. Основные HTML-теги

HTML состоит из тегов.

Например:

<p>Привет!</p>

<p> — начало тега
</p> — конец тега

Заголовки

<h1>Главный заголовок</h1>

<h2>Заголовок поменьше</h2>

<h3>Ещё меньше</h3>

Обычный текст

<p>Это обычный абзац текста.</p>

Ссылка

<a href="https://google.com">
    Открыть Google
</a>

Картинка

<img
    src=""
    alt="Картинка"
>

Список

<ul>
    <li>Игры</li>
    <li>Музыка</li>
    <li>Программирование</li>
</ul>
Мини-задание

Добавьте на страницу:

  • своё имя;
  • небольшой текст о себе;
  • 3 своих увлечения;
  • любимый сайт;
  • картинку.

Часть 4. Первое знакомство с CSS

HTML уже работает, но выглядит довольно просто.

CSS позволяет изменить внешний вид страницы.

Внутри <head> добавим:

<style>

    body {
        background: #eef2ff;
        font-family: Arial;
    }

    h1 {
        color: blue;
    }

    p {
        font-size: 18px;
    }

</style>

Здесь:

  • body — вся страница;
  • h1 — главный заголовок;
  • p — абзацы.

Несколько свойств CSS

color: red;

background: yellow;

font-size: 20px;

text-align: center;
На первом занятии не нужно запоминать свойства CSS. Главное — понять принцип: выбираем элемент → меняем его внешний вид.

Мини-проект

«Моя первая страница»

Теперь создайте собственную небольшую страницу.

На ней должны быть:

  1. Ваше имя
  2. Небольшое описание

Что мы сегодня узнали?

После первого занятия ученик должен уметь:
  • создать файл index.html;
  • открыть его в браузере;
  • понимать разницу между HTML и CSS;
  • использовать h1, p, a, img, ul, li;
  • изменить цвет, фон и размер текста через CSS;
  • создать простую страницу самостоятельно.

Небольшое домашнее задание

Добавьте:

Дополнительное задание: попробуйте самостоятельно узнать, что делает CSS-свойство border.
